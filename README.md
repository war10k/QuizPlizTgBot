# Telegram Bot для Квиз-команды на Cloudflare Workers

Универсальный автоматизированный Telegram-бот для синхронизации с API сайта интеллектуально-развлекательных игр «Квиз, плиз!». Бот работает на бессерверной платформе **Cloudflare Workers (Serverless)**, использует базу данных **Cloudflare KV** для хранения логов/опросов и интегрирован с графическим API **Pictify.io** для отрисовки турнирных таблиц.

## 🚀 Основной функционал

*   `/stats` — Вывод актуального рейтинга команды по 4 API-эндпоинтам (Сезонные и Общие зачеты Классики / Кино и Музыки).
*   `/nextgame` — Вывод актуальной текстовой афиши будущих игр в городе с автоматическим определением дня недели и встроенными гиперссылками на страницы игр.
*   `/poll` — Выводит интерактивное Inline-меню со списком всех будущих игр. При клике на игру бот автоматически публикует открытый опрос для сбора состава («Иду», «Иду + 1», «Без меня») и привязывает его к уникальному ID игры. В меню встроена кнопка «❌ Отмена» для безопасного удаления меню из чата.
*   `/ping` — Выводит Inline-меню со списком всех активных опросов. Капитан выбирает нужную игру, и бот автоматически тегает (со звуковым уведомлением) только тех участников команды, кто пропустил голосование по этому сбору. Глобальный список команды формируется автоматически на основе всех ранее голосовавших игроков.
*   `/hof` / `/halloffame` — Зал славы команды. Сгруппированный по лигам (Классика и Кино/Музыка) отчет по текущим рангам и очкам.
*   **Автоматические напоминания** — Каждый день ровно в 10:00 (по времени Новокузнецка) бот просыпается по Cron-триггеру, проверяет базу данных, и если сегодня или завтра запланирована игра, отправляет напоминание со списком идущих игроков.
*   **Автоматический трекер результатов** — Каждый час бот бесшумно опрашивает API сыгранных игр (строго через 2 часа после времени начала игры). Как только итоги опубликованы, бот отправляет персональное текстовое поздравление (в зависимости от занятого места от 1 до 20+), генерирует через Pictify.io качественную PNG-карточку итоговой таблицы раундов и подсвечивает строку вашей команды ярким маркером.
*   `/quiz` — Интерактивная разминка перед игрой (в процессе согласования базы данных).

## 🛠 Пошаговая инструкция по развертыванию

### Шаг 1. Создание и настройка Telegram-бота
1. Найдите в Telegram бота [@BotFather](https://t.me) и отправьте команду `/newbot`.
2. Скопируйте полученный **API токен** (`BOT_TOKEN`).
3. Добавьте созданного бота в вашу Telegram-группу и сделайте его **Администратором** (с правами на отправку сообщений и управление опросами).
4. Узнайте точный ID вашей группы (с минусом в начале, например `-1001234567890`), переслав любое сообщение из группы боту [@ShowJsonBot](https://t.me).

### Шаг 2. Создание базы данных Cloudflare KV
1. Зайдите в консоль [Cloudflare](https://cloudflare.com).
2. Перейдите в раздел **Storage & Databases** ➔ **KV**.
3. Нажмите **Create namespace**, введите имя `QUIZ_DB` и подтвердите создание. Скопируйте полученный **ID** базы данных из таблицы.

### Шаг 3. Безопасное сохранение секретных переменных в GitHub
Чтобы защитить приватные токены от кражи, добавим их в зашифрованные секреты репозитория:
1. Зайдите в ваш репозиторий на **GitHub** ➔ **Settings** ➔ **Secrets and variables** ➔ **Actions**.
2. Нажмите кнопку **New repository secret** и поочередно добавьте три секрета:
    * `CLOUDFLARE_API_TOKEN` — Ваш API-токен Cloudflare (создается в My Profile ➔ API Tokens ➔ шаблон Edit Cloudflare Workers).
    * `BOT_TOKEN` — Ваш токен от BotFather.
    * `CHAT_ID` — ID вашей группы (число с минусом, например -1001234567890, БЕЗ кавычек).

### Шаг 4. Конфигурация файлов локального проекта (CD-интеграция)
В корне вашей папки проекта на ПК должны быть созданы три конфигурационных файла для управления Git и утилитой Wrangler:

1. Создайте файл **`.gitignore`**:
```text
.wrangler/
```

2. Создайте файл **`wrangler.toml`**:
```toml
name = "donat-to-tea-bot"
main = "worker.js"
compatibility_date = "2026-06-09"

[[kv_namespaces]]
binding = "QUIZ_DB"
id = "СЮДА_ВСТАВЬТЕ_ID_ВАШЕЙ_БАЗЫ_ИЗ_ШАГА_2"

[vars]
TEAM_NAME = "Название команды"
CITY_SLUG = "nvkz"            # Префикс города для API рейтингов (nvkz, msk, nsk)
CITY_ID = "93"                 # Числовой ID города для API расписания

[ai]
binding = "AI"                 # Подключение локального модуля ИИ
```

3. Создайте файл сценария автоматического деплоя **`.github/workflows/deploy.yml`**:
```yaml
name: Deploy Worker

on:
  push:
    branches:
      - main
      - master

jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout repository
        uses: actions/checkout@v4

      - name: Deploy to Cloudflare Workers
        uses: cloudflare/wrangler-action@v3
        with:
          apiToken: ${{ secrets.CLOUDFLARE_API_TOKEN }}
          secrets: |
            BOT_TOKEN
            CHAT_ID
        env:
          BOT_TOKEN: ${{ secrets.BOT_TOKEN }}
          CHAT_ID: ${{ secrets.CHAT_ID }}
```

### Шаг 5. Активация расширенного вебхука в Telegram (Обязательно!)
По умолчанию Telegram не передает клики по кнопкам. Чтобы бот мгновенно перехватывал нажатия на меню `/poll`, `/ping` и клики в опросах, активируйте расширенные обновления. Откройте вкладку браузера и перейдите по ссылке:
```text
 https://api.telegram.org/bot<ВАШ_BOT_TOKEN>/setWebhook?url=https://<ИМЯ_ВОРКЕРА>.<ЮЗЕРНЕЙМ>.workers.dev&allowed_updates=["message","poll_answer","callback_query"]
```

### Шаг 6. Настройка Cron-расписания (Будильник бота)
1. В настройках воркера в Cloudflare перейдите на вкладку **Triggers** (Триггеры).
2. В блоке **Cron Triggers** нажмите **Add Trigger**.
3. Вставьте выражение: `*/30 * * * *` (проверка каждые 30 минут круглые сутки) и нажмите **Save**. Скрипт сам определит, когда наступит 10:00 утра по времени Новокузнецка (`Asia/Krasnoyarsk`) для отправки напоминаний, а в остальные часы будет проверять только результаты игр.

## 📁 Структура файлов репозитория

```text
├── .github/
│   └── workflows/
│       └── deploy.yml          # Сценарий автоматического деплоя из GitHub в Cloudflare
├── worker.js                   # Основной JavaScript-код логики бота
├── wrangler.toml               # Публичные конфигурации, переменные города и привязка KV
├── README.md                   # Текущая инструкция по развертыванию
└── .gitignore                  # Исключение временных файлов Wrangler из репозитория
```
