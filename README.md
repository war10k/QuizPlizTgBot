# 🍩 Telegram Bot для Квиз-команды

Автоматизированный Telegram-бот для синхронизации с API сайта «Квиз, плиз!». Бот работает на платформе **Cloudflare Workers (Serverless)**, использует встроенную базу данных **Cloudflare KV** для хранения логов и опросов, а также интегрирован с графическим API **Pictify.io** для отрисовки турнирных таблиц.

## 🚀 Основной функционал

*   `\stats` — Вывод актуального рейтинга команды по 4 API-эндпоинтам (Сезонные и Общие зачеты Классики / Кино и Музыки).
*   `\nextgame` — Поштучный вывод актуальной афиши будущих игр в городе.
*   `\poll` (в ответ на сообщение с игрой) — Создание открытого интерактивного опроса для сбора состава («Иду», «Иду + 1», «Без меня») с записью данных в KV.
*   **Автоматические напоминания** — Каждый день ровно в 10:00 (по местному времени) бот проверяет базу данных. Если сегодня или завтра игра, по которой запущен опрос, бот присылает напоминание с автоматическим подсчетом участников и списком идущих.
*   **Автоматический трекер результатов** — Каждый час бот бесшумно опрашивает API сыгранных игр. Как только Квиз, плиз! публикует итоги, бот отправляет поздравление, генерирует через Pictify.io красивую PNG-карточку турнирной таблицы раундов и автоматически подсвечивает строку вашей команды желтым маркером.
*   `\hof` / `\halloffame` — Зал славы команды. Сводный отчет по рангам и очкам, а также автоматические поздравления в чате, если утренний Cron-скрипт зафиксировал прирост баллов.

## 🛠 Пошаговая инструкция по развертыванию

### Шаг 1. Создание и настройка Telegram-бота
1. Найдите в Telegram официального бота [@BotFather](https://t.me) и отправьте команду `/newbot`.
2. Введите имя и юзернейм бота. Скопируйте полученный **API токен** (`BOT_TOKEN`).
3. Добавьте созданного бота в вашу Telegram-группу и сделайте его **Администратором** (с правами на отправку сообщений и управление опросами).
4. Узнайте точный ID вашей группы (с минусом в начале, например `-1001234567890`). Это можно сделать, переслав любое сообщение из группы боту [@ShowJsonBot](https://t.me).

### Шаг 2. Создание базы данных Cloudflare KV
1. Зайдите в консоль управления [Cloudflare](https://cloudflare.com).
2. В левом меню перейдите в раздел **Storage & Databases** ➔ **KV**.
3. Нажмите кнопку **Create namespace**, введите имя `QUIZ_DB` и подтвердите создание.

### Шаг 3. Создание и привязка Cloudflare Worker
1. В панели Cloudflare перейдите в **Workers & Pages** ➔ **Create application** ➔ **Create Worker**.
2. Укажите любое имя воркера (например, `quiz-please-bot`) и нажмите **Deploy**.
3. Нажмите кнопку **Edit code**, удалите стандартный шаблон и вставьте туда рабочий код JavaScript (`worker.js`).
4. **Связывание с базой данных**: Не выходя из воркера, перейдите на вкладку **Settings** (Настройки) ➔ **Variables** (Переменные) ➔ раздел **KV Namespace Bindings**. Нажмите **Add binding**.
    *   **Variable name**: `QUIZ_DB` (строго заглавными буквами).
    *   **KV namespace**: выберите из списка созданную на Шаге 2 базу `QUIZ_DB`.
    *   Нажмите **Save**.

### Шаг 4. Безопасное скрытие секретных переменных
Чтобы не публиковать приватные токены в открытый доступ на GitHub, добавим их в переменные окружения Cloudflare:
1. В настройках воркера (**Settings** ➔ **Variables**) найдите раздел **Environment Variables** и нажмите **Add variable**.
2. Добавьте три ключа:
    *   `BOT_TOKEN` — вставьте ваш токен от BotFather и обязательно нажмите кнопку **Encrypt** рядом.
    *   `CHAT_ID` — вставьте ID вашей группы (число с минусом, БЕЗ кавычек).
    *   `TEAM_NAME` — вставьте текстовое название вашей команды (например, `Там пончики к чаю`).
3. Нажмите **Save and Deploy**. Теперь код воркера обращается к ним безопасно через объект `env`.

### Шаг 5. Настройка Cron-расписания (Будильник бота)
Чтобы бот автоматически присылал напоминания и проверял результаты каждый час, настроим триггер:
1. В настройках воркера перейдите на вкладку **Triggers** (Триггеры).
2. В блоке **Cron Triggers** нажмите **Add Trigger**.
3. Чтобы бот просыпался каждые 30 или 60 минут круглые сутки, вставьте следующее выражение:
   ```text
   */30 * * * *
   ```
4. Нажмите **Save**. Скрипт сам внутри логики определит, когда наступит 10:00 утра по часовому поясу Новокузнецка (`Asia/Krasnoyarsk`), чтобы выдать напоминания, а в остальные часы будет проверять только результаты игр.

### Шаг 6. Активация вебхука в Telegram (Важный нюанс!)
По умолчанию Telegram передает ботам только текстовые сообщения. Чтобы бот мог ловить клики по кнопкам опроса («Иду», «Иду + 1»), нужно принудительно включить расширенный вебхук.
1. Откройте любую вкладку браузера на компьютере.
2. Соберите и вставьте в адресную строку следующую ссылку, подставив свой токен и скопированный URL воркера:
   ```text
   https://api.telegram.org/bot<ВАШ_BOT_TOKEN>/setWebhook?url=<URL_ВАШЕГО_ВОРКЕРА>.workers.dev&allowed_updates=["message","poll_answer"]
   ```
3. Нажмите **Enter**. На экране должна появиться строчка: `{"ok":true,"result":true,"description":"Webhook was set"}`.

## 🐙 Интеграция с GitHub и Continuous Deployment (CD)

Чтобы код автоматически обновлялся в Cloudflare каждый раз, когда вы делаете `git push` в свой репозиторий, настройте официальный GitHub Action от Cloudflare (Wrangler):

1. В корне вашего проекта на ПК создайте файл конфигурации **`wrangler.toml`**:
   ```toml
   name = "quiz-please-bot"
   main = "worker.js"
   compatibility_date = "2026-06-09"

   [[kv_namespaces]]
   binding = "QUIZ_DB"
   id = "ID_ВАШЕЙ_БАЗЫ_ДАННЫХ_ИЗ_ПАНЕЛИ_KV"
   ```
2. В личном кабинете Cloudflare перейдите в **My Profile** ➔ **API Tokens** ➔ **Create Token** ➔ выберите шаблон **Edit Cloudflare Workers** и скопируйте полученный токен.
3. Зайдите в ваш репозиторий на **GitHub** ➔ **Settings** ➔ **Secrets and variables** ➔ **Actions** ➔ **New repository secret**.
4. Добавьте секрет с именем `CLOUDFLARE_API_TOKEN` и вставьте туда скопированный токен.
5. Создайте в проекте папку `.github/workflows/` и положите туда файл `deploy.yml`:
   ```yaml
   name: Deploy Worker
   on:
     push:
       branches:
         - main
   jobs:
     deploy:
       runs-on: ubuntu-latest
       steps:
         - uses: actions/checkout@v3
         - name: Deploy to Cloudflare Workers
           uses: cloudflare/wrangler-action@v3
           with:
             apiToken: \${{ secrets.CLOUDFLARE_API_TOKEN }}
   ```

Теперь ваш проект полностью автоматизирован, скрыт от чужих глаз и развернут в облаке! Сладких побед вашей команде! 🍩🏆
