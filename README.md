# Telegram Bot для Квиз-команды на Cloudflare Workers

Универсальный автоматизированный Telegram-бот для синхронизации с API сайта интеллектуально-развлекательных игр «Квиз, плиз!». Бот работает на бессерверной платформе **Cloudflare Workers (Serverless)**, использует встроенную базу данных **Cloudflare KV** для хранения логов/опросов и интегрирован с графическим API **Pictify.io** для отрисовки турнирных таблиц.

## 🚀 Основной функционал

*   `/stats` — Вывод актуального рейтинга команды по 4 API-эндпоинтам (Сезонные и Общие зачеты Классики / Кино и Музыки).
*   `/nextgame` — Поштучный вывод актуальной афиши будущих игр в городе с автоматическим определением дня недели.
*   `/poll` — Создание открытого интерактивного опроса для сбора состава («Иду», «Иду + 1», «Без меня») с записью уникального ID игры в базу данных KV.
*   `/hof` / `/halloffame` — Зал славы команды. Сводный структурированный отчет по текущим рангам и очкам во всех лигах.
*   **Автоматические напоминания** — Каждый день ровно в 10:00 (по местному времени) бот просыпается по Cron-триггеру, проверяет базу данных, и если сегодня или завтра запланирована игра, отправляет напоминание со списком идущих игроков.
*   **Автоматический трекер результатов** — Каждый час бот бесшумно опрашивает API сыгранных игр (строго через 2 часа после времени начала игры). Как только итоги опубликованы, бот отправляет поздравление, генерирует через Pictify.io качественную PNG-карточку итоговой таблицы раундов и подсвечивает строку вашей команды ярким маркером.

## 🛠 Пошаговая инструкция по развертыванию

### Шаг 1. Создание и настройка Telegram-бота
1. Найдите в Telegram официального бота [@BotFather](https://t.me) и отправьте команду `/newbot`.
2. Введите имя и юзернейм бота. Скопируйте полученный **API токен** (`BOT_TOKEN`).
3. Добавьте созданного бота в вашу Telegram-группу и сделайте его **Администратором** (с правами на отправку сообщений и управление опросами).
4. Узнайте точный ID вашей группы (с минусом в начале, например `-1001234567890`). Это можно сделать, переслав любое сообщение из группы боту [@ShowJsonBot](https://t.me).

### Шаг 2. Создание базы данных Cloudflare KV
1. Зайдите в консоль управления [Cloudflare](https://cloudflare.com).
2. В левом меню перейдите в раздел **Storage & Databases** ➔ **KV**.
3. Нажмите кнопку **Create namespace**, введите имя `QUIZ_DB` и подтвердите создание. Скопируйте полученный **ID** базы данных из таблицы.

### Шаг 3. Безопасное сохранение секретных переменных в GitHub
Чтобы защитить приватные токены от кражи и не публиковать их в открытый доступ на GitHub, добавим их в зашифрованные секреты репозитория:
1. Зайдите в ваш созданный репозиторий на **GitHub** ➔ **Settings** ➔ **Secrets and variables** ➔ **Actions**.
2. Нажмите кнопку **New repository secret** и добавьте секрет для деплоя:
    * **Name:** `CLOUDFLARE_API_TOKEN`
    * **Value:** *Ваш API-токен Cloudflare (создается в My Profile ➔ API Tokens ➔ шаблон Edit Cloudflare Workers).*
3. Нажмите **New repository secret** еще раз и добавьте токен бота:
    * **Name:** `BOT_TOKEN`
    * **Value:** *Ваш токен от BotFather.*
4. Нажмите **New repository secret** в четвертый раз и добавьте ID чата:
    * **Name:** `CHAT_ID`
    * **Value:** *ID вашей группы с минусом (например, -1001234567890), БЕЗ кавычек.*

### Шаг 4. Конфигурация файлов локального проекта (CD-интеграция)
В корне вашей папки проекта на ПК должны быть созданы два конфигурационных файла для управления утилитой Wrangler:

1. Создайте файл **`wrangler.toml`** (здесь вы можете указать название вашей команды, а также префикс и ID абсолютно любого города присутствия франшизы «Квиз, плиз!»):
```toml
name = "donat-to-tea-bot"
main = "worker.js"
compatibility_date = "2026-06-09"

[[kv_namespaces]]
binding = "QUIZ_DB"
id = "ВСТАВЬТЕ_СЮДА_ID_ВАШЕЙ_БАЗЫ_ИЗ_ШАГА_2"

[vars]
TEAM_NAME = "Название команды"
CITY_SLUG = "nvkz"             # Префикс города для API рейтингов (например, nvkz, msk, nsk)
CITY_ID = "93"                # Числовой ID города для API расписания (можно узнать в DevTools сайта)
```

2. Создайте файл сценария автоматического деплоя **`.github/workflows/deploy.yml`**:
```yaml
name: Deploy Worker

on:
  push:
    branches:
      - main
      - master

jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout repository
        uses: actions/checkout@v4

      - name: Deploy to Cloudflare Workers
        uses: cloudflare/wrangler-action@v3
        with:
          apiToken: ${{ secrets.CLOUDFLARE_API_TOKEN }}
          secrets: |
            BOT_TOKEN
            CHAT_ID
        env:
          BOT_TOKEN: ${{ secrets.BOT_TOKEN }}
          CHAT_ID: ${{ secrets.CHAT_ID }}
```

### Шаг 5. Активация расширенного вебхука в Telegram
По умолчанию Telegram передает ботам только текстовые сообщения. Чтобы бот мог перехватывать клики по кнопкам опроса («Иду», «Иду + 1») и мгновенно сохранять их в базу данных, нужно активировать расширенные обновления.
1. Откройте любую вкладку браузера на компьютере.
2. Вставьте в адресную строку следующую ссылку, подставив свой токен и скопированный URL воркера из панели Cloudflare:
   ```text
   https://api.telegram.org/bot<ВАШ_BOT_TOKEN>/setWebhook?url=https://<ИМЯ_ВОРКЕРА>.<ЮЗЕРНЕЙМ>.workers.dev&allowed_updates=["message","poll_answer"]
   ```
3. Нажмите **Enter**. На экране должен появиться ответ: `{"ok":true,"result":true,"description":"Webhook was set"}`.

### Шаг 6. Настройка Cron-расписания (Будильник бота)
Чтобы бот автоматически просыпался для проверки результатов и отправки напоминаний, настроим триггер в панели Cloudflare:
1. В настройках воркера на сайте Cloudflare перейдите на вкладку **Triggers** (Триггеры).
2. В блоке **Cron Triggers** нажмите **Add Trigger**.
3. Чтобы бот проверял результаты каждую половину часта круглые сутки, вставьте выражение: `*/30 * * * *` и нажмите **Save**.

```text

│   └── workflows/
│       └── deploy.yml          # Сценарий автоматического деплоя из GitHub в Cloudflare

├── wrangler.toml               # Публичные конфигурации и привязка KV базы данных

└── .gitignore                  # Исключение временных файлов Wrangler из репозитория
```
